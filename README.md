# Budgetly 💰

A modern React.js budgeting application that helps users manage income and expenses with a clean, responsive interface.

## 🚀 Live Demo

https://budgetly-phi.vercel.app/

## 📂 GitHub Repository

https://github.com/zreeeharii/budgetly

## ✨ Features

- 💸 Add Income & Expenses
- 🗑️ Delete Transactions
- 🔍 Search Transactions
- 💾 Local Storage Support
- 🌙 Dark / Light Mode
- 📱 Responsive Design
- ⚡ Modern UI with Animations

## 🛠️ Tech Stack

- React.js
- Vite
- CSS3
- React Icons

## 📦 Installation

```bash
git clone https://github.com/zreeeharii/budgetly.git
cd budgetly
npm install
npm run dev
```
