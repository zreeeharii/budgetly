# Budgetly 💰

A modern React.js budgeting application for tracking income and expenses.

## Features

- 💸 Add Income & Expenses
- 🗑 Delete Transactions
- 🔍 Search Transactions
- 💾 Local Storage Support
- 🌙 Dark Mode
- 📱 Fully Responsive
- ⚡ Modern Dashboard UI

## Tech Stack

- React.js
- CSS3
- React Icons

## Installation

```bash
npm install
npm run dev
